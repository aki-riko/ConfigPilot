# ConfigPilot v1.0.26

本版本增加 ChatGPT 会话刷新入口，并修正 GPT-5.6 思考等级配置。

## 主要更新

- 新增“修复 401（刷新 ChatGPT 会话）”入口，使用现有 refresh token 更新过期的 ChatGPT 会话。
- GPT-5.6 普通思考等级增加 `MAX`，远端模型目录同步时按模型静态能力过滤 `max`。
- 保持 Ultra 多代理模式与普通思考等级选择器的边界不变。

## 下载

- Windows：`ConfigPilot_Setup_1.0.26.exe`
- macOS Apple Silicon：`ConfigPilot_1.0.26_arm64.dmg`

## macOS 首次安装须知

当前 macOS 版本仅支持 Apple Silicon（M 系列芯片），不支持 Intel Mac。

维护者目前没有 Apple Developer Program 会员，因此 DMG 尚未使用 Developer ID 签名和苹果公证。请只从本项目官方 Releases 下载。安装后如被 Gatekeeper 阻止，请执行：

```bash
xattr -dr com.apple.quarantine "/Applications/ConfigPilot.app"
open "/Applications/ConfigPilot.app"
```
