# ConfigPilot v1.0.27

本版本修复 Codex 新版中转站 401 认证问题，并保留 ChatGPT OAuth 会话凭据。

## 主要更新

- 新增独立的“修复中转站 401”入口，按钮不会因当前没有可读 key 而灰掉。
- 明确输入中转站 API key 时，配置 provider 的 `env_key` 并同步用户环境变量。
- 已有 API key 在 `auth.json` 时，使用 Codex 的 auth.json 认证路径，不额外写环境变量。
- 修复中转站认证时不再覆盖已有 ChatGPT OAuth 凭据。

## 下载

- Windows：`ConfigPilot_Setup_1.0.27.exe`
- macOS Apple Silicon：`ConfigPilot_1.0.27_arm64.dmg`

## macOS 首次安装须知

当前 macOS 版本仅支持 Apple Silicon（M 系列芯片），不支持 Intel Mac。

维护者目前没有 Apple Developer Program 会员，因此 DMG 尚未使用 Developer ID 签名和苹果公证。请只从本项目官方 Releases 下载。安装后如被 Gatekeeper 阻止，请执行：

```bash
xattr -dr com.apple.quarantine "/Applications/ConfigPilot.app"
open "/Applications/ConfigPilot.app"
```
