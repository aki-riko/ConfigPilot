# ConfigPilot v1.0.31

本版本新增百万上下文预设，并修复余额桌宠启动时的 QML 高度绑定环。

## 新增

- Codex 上下文配置新增「套用百万上下文」：上下文窗口 `1,000,000`，自动压缩阈值 `900,000`，工具输出保留量 `6,000`。
- 原有「稳定上下文」预设保留不变。

## 修复

- 修复余额桌宠启动时 `PetWindow.panelHeight` 与 `PetPanel.panelHeight` 互相绑定导致的 QML `Binding loop` 警告。
- 高度状态改为由窗口单向维护，保留明细展开、收缩延迟和桌宠定位行为。

## 下载

- Windows：`ConfigPilot_Setup_1.0.31.exe`
- macOS Apple Silicon：`ConfigPilot_1.0.31_arm64.dmg`

## macOS 首次安装须知

当前 macOS 版本仅支持 Apple Silicon（M 系列芯片），不支持 Intel Mac。

维护者目前没有 Apple Developer Program 会员，因此 DMG 尚未使用 Developer ID 签名和苹果公证。请只从本项目官方 Releases 下载。安装后如被 Gatekeeper 阻止，请执行：

```bash
xattr -dr com.apple.quarantine "/Applications/ConfigPilot.app"
open "/Applications/ConfigPilot.app"
```
