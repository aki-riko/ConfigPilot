# ConfigPilot v1.0.28

本版本修正 CC Switch 切换后中转站 401 的恢复逻辑。

## 主要修复

- “修复中转站 401”现在始终把当前中转 key 写入 provider 的 `env_key` 环境变量认证路径。
- 即使 key 原本保存在 `auth.json`，也会一次完成认证来源迁移，不再因为已有 key 而无操作。
- 保留 `auth.json` 原内容，不覆盖 ChatGPT OAuth 会话或其它凭据。
- 重复点击修复按钮保持幂等，避免反复重启和尝试才能恢复。

## 下载

- Windows：`ConfigPilot_Setup_1.0.28.exe`
- macOS Apple Silicon：`ConfigPilot_1.0.28_arm64.dmg`

## macOS 首次安装须知

当前 macOS 版本仅支持 Apple Silicon（M 系列芯片），不支持 Intel Mac。

维护者目前没有 Apple Developer Program 会员，因此 DMG 尚未使用 Developer ID 签名和苹果公证。请只从本项目官方 Releases 下载。安装后如被 Gatekeeper 阻止，请执行：

```bash
xattr -dr com.apple.quarantine "/Applications/ConfigPilot.app"
open "/Applications/ConfigPilot.app"
```
