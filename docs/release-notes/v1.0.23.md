# ConfigPilot v1.0.23

本版本修正 ConfigPilot 与 PrismQML Gallery 共用引擎外观配置的问题，并升级到支持宿主独立配置路径的 PrismQML 正式版本。

## 主要更新

- PrismQML 引擎配置改为 ConfigPilot 独占文件。
- Windows 使用 `%LOCALAPPDATA%\ConfigPilot\prismqml.json`。
- macOS 和 Linux 使用 `$XDG_CONFIG_HOME/ConfigPilot/prismqml.json`；未设置时回退到 `~/.config/ConfigPilot/prismqml.json`。
- 启动期 DPI、主题、皮肤、语言和主题色均从 ConfigPilot 自己的配置读取，不再受 Gallery 配置影响。
- PrismQML 运行依赖固定升级到 `0.4.0.8`。

## 下载

- Windows：`ConfigPilot_Setup_1.0.23.exe`
- macOS Apple Silicon：`ConfigPilot_1.0.23_arm64.dmg`

## macOS 首次安装须知

当前 macOS 版本仅支持 Apple Silicon（M 系列芯片），不支持 Intel Mac。

维护者目前没有 Apple Developer Program 会员，因此 DMG 尚未使用 Developer ID 签名和 Apple 公证。请只从本项目官方 Releases 下载。安装后如被 Gatekeeper 阻止，请执行：

```bash
xattr -dr com.apple.quarantine "/Applications/ConfigPilot.app"
open "/Applications/ConfigPilot.app"
```
