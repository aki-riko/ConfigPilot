# ConfigPilot v1.0.21

本版本新增 Codex ChatGPT refresh token 登录，可用单个 refresh token 换取并安全保存完整 OAuth 凭据。

## 主要更新

- 在“连接与认证”中新增 ChatGPT Refresh Token 登录入口，输入内容按密码字段处理，提交后立即清空。
- 按 Codex 官方当前协议请求 `https://auth.openai.com/oauth/token`，使用官方公开客户端标识交换 `id_token`、`access_token` 和旋转后的 `refresh_token`。
- 登录前校验 JWT 与 `chatgpt_account_id`；凭据不完整时拒绝写入，避免生成不可用的 `auth.json`。
- 写入 `~/.codex/auth.json` 前自动保留 `auth.json.bak`，并使用临时文件原子替换。
- 识别 refresh token 过期、重复使用、撤销和无效等错误，不在通知或日志中输出 token 原文。
- OAuth 地址、客户端标识和超时值由 `app_config.json` 管理，同时兼容 Codex 官方环境覆盖项。

## 使用说明

1. 打开 ConfigPilot 的 Codex 页面。
2. 在“ChatGPT Refresh Token”中粘贴完整 refresh token。
3. 点击“登录 ChatGPT”，等待成功通知。
4. 完全退出并重新启动 Codex。

成功登录后，后续 access token 更新由 Codex 使用已保存的 refresh token 自动完成。

## macOS 首次安装须知

当前 macOS 版本仅支持 Apple Silicon（M 系列芯片），不支持 Intel Mac。

维护者目前没有 Apple Developer Program 会员，因此 DMG 尚未使用 Developer ID 签名和 Apple 公证。macOS Gatekeeper 可能显示“ConfigPilot 已损坏，无法打开”，但这不代表 DMG 文件真的损坏。

请先把 `ConfigPilot` 拖入 `Applications`，再打开“终端”执行：

```bash
xattr -dr com.apple.quarantine "/Applications/ConfigPilot.app"
open "/Applications/ConfigPilot.app"
```
