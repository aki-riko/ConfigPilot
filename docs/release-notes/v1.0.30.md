# ConfigPilot v1.0.30

本版本修复 Codex 页底部操作栏消失的问题，升级内置 PrismQML 引擎，并针对 Codex 在 Windows 上的沙盒初始化循环提供临时止血开关。

## 主要修复

- 恢复 Codex 页底部常驻操作栏（未应用状态提示与「重新读取 / 应用配置」按钮）。此前该栏高度表达式引用了页面上并不存在的属性，高度计算结果无效，整栏不显示，看起来像按钮“丢了”。
- 内置 PrismQML 引擎升级至 `0.4.2.24`：包含页面懒加载切换的稳定性修复（0.4.2.19 起改为命令式装载，避免切换过程中的装载中断），以及下拉预热点与弹层阴影时序修正。

## 新增

- Codex 连接分区新增「沙盒止血（临时）」：一键把 `~/.codex/config.toml` 顶层的 `sandbox_mode` 写为 `danger-full-access`，用于绕过 Codex 在 Windows 上的沙盒初始化循环（表现为一直提示「无法检查 Windows 设置」）。
  - 只写这一个字段：`[windows]`、`[projects.*]`、`notify` 与各供应商配置全部原样保留。
  - 写入前照常备份 `config.toml.bak`；写入后可用「恢复初始设置」还原，且不会覆盖此后被外部修改过的值。
  - 若配置里已存在表内的同名 `sandbox_mode`，ConfigPilot 会拒绝写入并提示，避免误改他人配置。
- 该开关会关闭 Codex 的沙盒隔离能力（等同把文件系统权限放到最宽），仅在确实遇到初始化循环、并清楚代价时临时使用。

## macOS 首次安装须知

当前 macOS 版本仅支持 Apple Silicon（M 系列芯片），不支持 Intel Mac。

维护者目前没有 Apple Developer Program 会员，因此 DMG 尚未使用 Developer ID 签名和苹果公证。请只从本项目官方 Releases 下载。安装后如被 Gatekeeper 阻止，请执行：

```bash
xattr -dr com.apple.quarantine "/Applications/ConfigPilot.app"
open "/Applications/ConfigPilot.app"
```
