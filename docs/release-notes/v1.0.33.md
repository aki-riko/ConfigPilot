# ConfigPilot v1.0.33

本版本升级 PrismQML 引擎，并调整 Codex 上下文与子代理默认配置。

## 变更

- PrismQML 引擎升级至 PyPI 正式版 `prismqml==0.5.0.23`。
- 「修复降智」将子代理默认模型设为 `gpt-6-sol`，推理强度保持为 `high`。
- 「套用百万上下文」使用精确二进制百万：上下文窗口 `1,048,576`，自动压缩阈值 `943,718`，工具输出保留量 `6,000`。

## 下载

- Windows：`ConfigPilot_Setup_1.0.33.exe`
- macOS Apple Silicon：`ConfigPilot_1.0.33_arm64.dmg`

## macOS 首次安装须知

当前 macOS 版本仅支持 Apple Silicon（M 系列芯片），不支持 Intel Mac。

维护者目前没有 Apple Developer Program 会员，因此 DMG 尚未使用 Developer ID 签名和苹果公证。请只从本项目官方 Releases 下载。安装后如被 Gatekeeper 阻止，请执行：

```bash
xattr -dr com.apple.quarantine "/Applications/ConfigPilot.app"
open "/Applications/ConfigPilot.app"
```
