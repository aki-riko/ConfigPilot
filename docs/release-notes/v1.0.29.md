# ConfigPilot v1.0.29

本版本升级内置 PrismQML 引擎，并重做关于页与设置入口。

## 主要变更

- 内置 PrismQML 引擎升级至 `0.4.2.7`，包含懒加载页面退场、FastSplash 退场节奏与弹层阴影时序修复。
- 关于卡片与“检查更新”合并为一张卡片，标题中的 ConfigPilot 直接链接项目主页，不再单列“项目主页”按钮。
- 导航中的“帮助”改为“设置”，并同步导航图标。
- 更新卡片只显示 ConfigPilot 自身版本，不再混入引擎版本。
- Codex 思考档位支持 GPT-5.6 Ultra，档位仅保留 MAX 并本地化显示。
- Claude 支持结构化模型设置，ConfigPilot 的 Claude 配置与 CC Switch 配置相互隔离，导入流程提示更清晰。
- 统一各配置页面排版与按钮尺寸。

## 下载

- Windows：`ConfigPilot_Setup_1.0.29.exe`
- macOS Apple Silicon：`ConfigPilot_1.0.29_arm64.dmg`

## macOS 首次安装须知

当前 macOS 版本仅支持 Apple Silicon（M 系列芯片），不支持 Intel Mac。

维护者目前没有 Apple Developer Program 会员，因此 DMG 尚未使用 Developer ID 签名和苹果公证。请只从本项目官方 Releases 下载。安装后如被 Gatekeeper 阻止，请执行：

```bash
xattr -dr com.apple.quarantine "/Applications/ConfigPilot.app"
open "/Applications/ConfigPilot.app"
```
