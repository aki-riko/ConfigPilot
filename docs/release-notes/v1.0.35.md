# ConfigPilot v1.0.35

本版本让「获取模型」失败时直接告诉你**是哪一类错误、下一步该改什么**，不再只丢一句 `HTTP 401: Unauthorized`。

## 变更

- **错误码提示（新增 `backend/upstream_errors.py`）**：「获取模型」失败时按上游返回的 HTTP 状态码翻译成可操作的中文提示，并附上中转站自己返回的原始 message：
  - `401` → API Key 无效、已过期或未填写，请检查「API 密钥」后重试
  - `402` → 账户额度不足或未付费，请到中转站充值后重试
  - `403` → Key 可能没有该模型的权限，或被站点防护拦截
  - `404` → 接口路径不存在，请检查 API 地址是否正确（通常应以 `/v1` 结尾）
  - `429` → 请求过于频繁或已触发限流，请稍后再试
  - `500/502/503/504` → 上游服务器或网关问题（与本地配置无关），请稍后重试
  - 网络层失败（DNS/代理/TLS）→ 提示检查网络与地址可达性，并保留底层原因
- **识别「地址填错」**：把 API 地址填成站点主页时，上游会返回 `200` + 一页 HTML。此前只会报 `Expecting value: line 1 column 1`；现在明确指出「返回的是网页而不是 JSON，API 地址可能填成了站点主页」，且不再把整页 HTML 塞进通知条。
- **兼容多家错误体格式**：同时解析 new-api / one-api 的 `{"error":{"message":...}}`、官方 OpenAI 的 `invalid_request_error`、扁平的 `{"message":...}` 与 `{"error":"..."}`。
- **密钥不回流**：若上游在报错里回显了你的 Key，提示中会自动替换成 `***`。
- **桌宠余额监控同步补全**：`401` / `402` 也会给出「Key 失效 / 额度不足」的原因说明，其余原有提示（`404` 非 new-api 站点、`403` 前置防护）保持不变。

## 升级说明

Windows 与 macOS 都可直接在应用内升级；macOS 会打开官方 Release 页面下载 DMG。

## 下载

- Windows：`ConfigPilot_Setup_1.0.35.exe`
- macOS Apple Silicon：`ConfigPilot_1.0.35_arm64.dmg`

## macOS 首次安装须知

当前 macOS 版本仅支持 Apple Silicon（M 系列芯片），不支持 Intel Mac。

维护者目前没有 Apple Developer Program 会员，因此 DMG 尚未使用 Developer ID 签名和苹果公证。请只从本项目官方 Releases 下载。安装后如被 Gatekeeper 阻止，请执行：

```bash
xattr -dr com.apple.quarantine "/Applications/ConfigPilot.app"
open "/Applications/ConfigPilot.app"
```
