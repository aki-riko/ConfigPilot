# ConfigPilot v1.0.25

本版本修复 Codex 自定义 provider 的认证来源识别与模型探测不一致问题。

## 主要更新

- 正确识别 `auth.json`、`env_key` 环境变量和无认证三种 Codex provider 认证方式。
- 使用 API key 或 ChatGPT 凭据时，自动切换 provider 到 `requires_openai_auth`，避免继续使用旧的 `env_key`。
- 获取模型列表复用当前 provider 的实际认证来源，不再只读取 `auth.json`。
- 环境变量缺失时在界面明确显示认证未设置，避免出现“密钥已设置”但 Codex 实际收到空 Authorization 的误导状态。
- 兼容带 UTF-8 BOM 的 Codex `auth.json`。
- 修正 `requires_openai_auth` 的界面说明。

## 下载

- Windows：`ConfigPilot_Setup_1.0.25.exe`
- macOS Apple Silicon：`ConfigPilot_1.0.25_arm64.dmg`

## macOS 首次安装须知

当前 macOS 版本仅支持 Apple Silicon（M 系列芯片），不支持 Intel Mac。

维护者目前没有 Apple Developer Program 会员，因此 DMG 尚未使用 Developer ID 签名和苹果公证。请只从本项目官方 Releases 下载。安装后如被 Gatekeeper 阻止，请执行：

```bash
xattr -dr com.apple.quarantine "/Applications/ConfigPilot.app"
open "/Applications/ConfigPilot.app"
```
