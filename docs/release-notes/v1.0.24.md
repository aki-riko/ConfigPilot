# ConfigPilot v1.0.24

本版本修复 PrismQML 0.4.0.8 升级后的启动屏兼容问题。

## 主要更新

- 适配 PrismQML 0.4+ 的内置启动屏生命周期。
- 移除业务侧重复创建和覆盖 `_splashInstance` 的旧逻辑。
- 修复启动后一直停留在“正在加载...”画面、主界面无法显示的问题。
- 保留 ConfigPilot 独立的 PrismQML 外观配置文件和现有启动画面视觉。

## 下载

- Windows：`ConfigPilot_Setup_1.0.24.exe`
- macOS Apple Silicon：`ConfigPilot_1.0.24_arm64.dmg`

## macOS 首次安装须知

当前 macOS 版本仅支持 Apple Silicon（M 系列芯片），不支持 Intel Mac。

维护者目前没有 Apple Developer Program 会员，因此 DMG 尚未使用 Developer ID 签名和苹果公证。请只从本项目官方 Releases 下载。安装后如被 Gatekeeper 阻止，请执行：

```bash
xattr -dr com.apple.quarantine "/Applications/ConfigPilot.app"
open "/Applications/ConfigPilot.app"
```
