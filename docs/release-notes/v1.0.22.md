# ConfigPilot v1.0.22

本版本将 v1.0.21 的单个 refresh token 输入改为 ChatGPT 认证 JSON 导入，并对照 codex2api 的现有导入格式补齐兼容性。

## 主要更新

- “连接与认证”新增多行 JSON 粘贴框，提交后立即清空输入内容。
- 支持完整 Codex `auth.json` 的 `tokens` 结构。
- 支持 codex2api 风格的扁平单账号 JSON，以及 `accounts[].credentials` 单账号结构。
- 同时兼容 `access_token` / `accessToken`、`id_token` / `idToken`、`account_id` / `accountId` 等字段名。
- JSON 已包含 `id_token`、`access_token`、`refresh_token` 和 `account_id` 时直接安全写入，不发起额外网络请求。
- JSON 只有完整 `refresh_token` 时，通过 Codex 官方 OAuth 接口换取其余凭据，并保留服务端旋转后的 refresh token。
- 拒绝 access-token-only 和多账号 JSON，避免生成 Codex 无法持续刷新的认证文件或误选账号。
- 写入前继续保留 `auth.json.bak`，并使用原子替换与恢复记录。

## 使用说明

1. 打开 ConfigPilot 的 Codex 页面。
2. 在“ChatGPT JSON 导入”中粘贴单账号 JSON。
3. 点击“导入并登录 ChatGPT”。
4. 完全退出并重新启动 Codex。

可直接使用以下任一结构：

```json
{
  "refresh_token": "REFRESH_TOKEN"
}
```

```json
{
  "auth_mode": "chatgpt",
  "tokens": {
    "id_token": "ID_TOKEN",
    "access_token": "ACCESS_TOKEN",
    "refresh_token": "REFRESH_TOKEN",
    "account_id": "ACCOUNT_ID"
  }
}
```

## macOS 首次安装须知

当前 macOS 版本仅支持 Apple Silicon（M 系列芯片），不支持 Intel Mac。

维护者目前没有 Apple Developer Program 会员，因此 DMG 尚未使用 Developer ID 签名和 Apple 公证。请只从本项目官方 Releases 下载。安装后如被 Gatekeeper 阻止，请执行：

```bash
xattr -dr com.apple.quarantine "/Applications/ConfigPilot.app"
open "/Applications/ConfigPilot.app"
```
