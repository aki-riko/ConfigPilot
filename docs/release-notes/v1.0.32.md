# ConfigPilot v1.0.32

本版本将 PrismQML 引擎升级为 PyPI 正式发布的 0.5.0.15，移除本地 .pth 依赖方案。无功能与界面变化。

## 变更

- PrismQML 引擎依赖切换为 `prismqml==0.5.0.15` 正式 wheel，不再通过 `prismqml_local.pth` 指向本地框架检出。
- 0.5.0.15 已包含余额桌宠气泡依赖的三项框架能力：TipPopup 公开可配的 `viewWidth` / `viewHeight`、TipPopupWindow 的 `customContentHost`、Qt.Tool 窗口上 `mapToGlobal` 的坐标退化修复，桌宠气泡行为与上一版一致。

## 下载

- Windows：`ConfigPilot_Setup_1.0.32.exe`
- macOS Apple Silicon：`ConfigPilot_1.0.32_arm64.dmg`

## macOS 首次安装须知

当前 macOS 版本仅支持 Apple Silicon（M 系列芯片），不支持 Intel Mac。

维护者目前没有 Apple Developer Program 会员，因此 DMG 尚未使用 Developer ID 签名和苹果公证。请只从本项目官方 Releases 下载。安装后如被 Gatekeeper 阻止，请执行：

```bash
xattr -dr com.apple.quarantine "/Applications/ConfigPilot.app"
open "/Applications/ConfigPilot.app"
```
